# Driver Flow

## Full Journey

```
Sign Up → Apply → Get Approved → Add Bank → Create Trip → Manage Bookings → Start → Complete → Get Paid
```

---

## Step 1: Sign Up

Same as passenger signup. Role starts as `passenger`.

```typescript
const { data } = await supabase.auth.signUp({
  email: 'driver@example.com',
  password: 'password123',
})
```

---

## Step 2: Submit Driver Application

```typescript
await supabase.from('driver_profiles').insert({
  user_id: userId,
  license_number: 'LIC123456',
  license_expiry: '2027-01-01',
  vehicle_make: 'Toyota',
  vehicle_model: 'Camry',
  vehicle_year: 2020,
  vehicle_color: 'Black',
  plate_number: 'LAG-123-XY',
  total_seats: 4,
})
```

Upload license image:

```typescript
await supabase.storage.from('driver-docs')
  .upload(`${userId}/license.jpg`, licenseFile, { upsert: true })
```

---

## Step 3: Wait for Approval

Poll or listen for approval status change:

```typescript
// Poll
const { data } = await supabase
  .from('driver_profiles')
  .select('approval_status')
  .single()

// Or subscribe via Realtime
supabase.channel('driver-approval')
  .on('postgres_changes', {
    event: 'UPDATE',
    schema: 'public',
    table: 'driver_profiles',
    filter: `user_id=eq.${userId}`,
  }, (payload) => {
    if (payload.new.approval_status === 'approved') {
      // Unlock driver features
    }
  })
  .subscribe()
```

---

## Step 4: Add Bank Account

```typescript
// 1. Get bank list
const { data: { banks } } = await supabase.functions.invoke('get-paystack-banks')

// 2. Resolve account name for confirmation
const { data: { account_name } } = await supabase.functions.invoke('resolve-account-name', {
  body: { account_number: '0123456789', bank_code: '058' }
})

// 3. Save bank account
await supabase.functions.invoke('add-bank-account', {
  body: { driver_id: userId, account_number: '0123456789', bank_code: '058' }
})
```

---

## Step 5: Create a Trip

```typescript
const { data } = await supabase.functions.invoke('create-trip', {
  body: {
    driver_id: userId,
    start_location: { latitude: 6.5244, longitude: 3.3792 },
    end_location: { latitude: 7.3776, longitude: 3.9470 },
    price_per_seat_kobo: 150000,
    total_seats: 3,
    departure_time: '2025-03-15T08:00:00Z',
  }
})
```

---

## Step 6: Manage Incoming Bookings

Listen for new booking requests:

```typescript
supabase.channel('trip-bookings')
  .on('postgres_changes', {
    event: 'INSERT',
    schema: 'public',
    table: 'bookings',
    filter: `trip_id=eq.${tripId}`,
  }, (payload) => {
    // New booking request — show accept/reject UI
  })
  .subscribe()

// Accept
await supabase.from('bookings')
  .update({ status: 'accepted' })
  .eq('id', bookingId)

// Reject
await supabase.from('bookings')
  .update({ status: 'rejected' })
  .eq('id', bookingId)
```

---

## Step 7: Verify Passenger PINs

At pickup, driver enters passenger's 4-digit PIN:

```typescript
const { data, error } = await supabase.functions.invoke('verify-pin', {
  body: { driver_id: userId, booking_id: bookingId, boarding_pin: pinInput }
})

if (error) {
  // Show "Invalid PIN" message
} else {
  // Passenger verified — allow boarding
}
```

Mark no-shows (after 10 minutes):

```typescript
await supabase.functions.invoke('mark-no-show', {
  body: { booking_id: bookingId }
})
```

---

## Step 8: Send Location During Trip

```typescript
// Send GPS ping every 5–10 seconds during active trip
const interval = setInterval(async () => {
  const { latitude, longitude } = await getCurrentLocation()
  await supabase.from('driver_locations').insert({
    driver_id: userId,
    trip_id: tripId,
    location: `POINT(${longitude} ${latitude})`,
    speed_kmh: currentSpeed,
    heading: currentHeading,
  })
}, 5000)
```

---

## Step 9: Start Trip

Once all passengers are verified (or no-shows marked):

```typescript
const { data, error } = await supabase.functions.invoke('start-trip', {
  body: { driver_id: userId, trip_id: tripId }
})
```

---

## Step 10: Complete Trip & Get Paid

```typescript
const { data } = await supabase.functions.invoke('complete-trip', {
  body: { driver_id: userId, trip_id: tripId }
})
// data.payout_id — payout is now scheduled
// If payout_preference is 'auto', wallet is credited immediately
```

Check wallet balance after completion:

```typescript
const { data: wallet } = await supabase
  .from('wallets')
  .select('balance_kobo')
  .single()
```
